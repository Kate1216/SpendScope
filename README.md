# SpendScope

SpendScope 是一个面向学生和年轻用户的 AI 月度账单分析工具。用户可以上传微信、支付宝、银行卡等平台导出的账单文件，系统会在浏览器本地完成解析、清洗、分类、统计、图表展示和月度总结，帮助用户快速了解一个月的钱主要花在了哪里。

## 在线体验

https://spendscopekate.netlify.app

## 核心功能

- 支持上传 `.csv`、`.xlsx`、`.xls`、`.pdf` 账单文件，可一次选择多个文件。
- 支持微信 Excel 账单、支付宝文字型 PDF 账单等多格式解析。
- 自动统一字段为时间、平台、交易对象、交易类型、交易说明、收支类型、金额和消费类别。
- 支持退款抵扣、余额宝收益识别、账户转移排除等更接近真实消费的统计口径。
- 展示总收入、总支出、净收入 / 净支出、消费笔数等核心指标。
- 支持分类支出饼图、平台支出柱状图、每日支出趋势折线图。
- 支持账单明细搜索、表头筛选、手动修改收支类型和类别。
- 支持自定义新增分类，并保存到浏览器本地。
- 支持本地保存当前报告、刷新恢复、删除本地报告。
- 支持导出 Excel 明细和 PDF 月度报告。
- 基于统计摘要生成 AI 风格月度消费总结，不向模型发送完整账单明细。

## 分类体系

SpendScope 当前将交易分为四种处理类型：

- 支出：真实消费，计入总支出。
- 收入：真实进账，计入总收入。
- 退款：用于抵扣支出，不算普通收入。
- 排除：不参与统计，例如账户互转、自动转入、亲情卡、重复流水等。

支出分类包括：交通、学习、正餐、奶茶咖啡、零食水果、聚餐、运动、购物、娱乐、手工爱好、宠物、旅行、日常开销、化妆护肤、群收款和其他。

收入分类包括：生活费、兼职、工资、群收款、理财、礼金和其他。

## 项目亮点

- **多格式账单解析**：支持常见表格账单，也支持支付宝文字型 PDF 账单。
- **真实消费口径**：对退款、收益、补偿、账户转移等特殊流水进行二次处理。
- **学生化分类体系**：针对学生和年轻用户的消费场景设计分类，例如正餐、奶茶咖啡、聚餐、宠物、手工爱好等。
- **可校正的明细分类**：用户可以手动修改每笔账单的类型和类别，提升统计可信度。
- **隐私友好**：账单数据默认在浏览器本地处理，不默认上传服务器。

## 使用方式

直接用浏览器打开 `index.html` 即可体验。

> Excel、PDF 和图表功能依赖浏览器加载 CDN 上的 SheetJS、PDF.js、Chart.js 和 html2pdf.js。如果离线使用，需要把这些库下载到本地并替换 `index.html` 里的脚本地址。

## 隐私说明

SpendScope 当前版本在浏览器本地解析账单文件。只有用户点击“保存到本地”后，解析后的报告数据才会保存在当前浏览器的 localStorage 中。用户可以通过“删除当前报告”清除本地数据。

当前版本不会默认上传完整账单文件或完整账单明细到服务器。

## 当前版本说明

当前 AI 月度总结为基于统计摘要的本地规则生成，语气和结构按真实 AI 报告设计。后续可接入 OpenAI、Claude、DeepSeek 等模型 API，仅将统计摘要发送给模型，以生成更自然的消费分析报告。
